More help

Which methods can be enumerated exactly?

Only systematic sampling with a whole-number interval k = N/n. The random start is its only random step, so there are just k equally likely samples; listing all k gives the exact distribution, and drawing 1,000 random starts would only repeat them. Simple random sampling, stratified sampling and the fractional-interval design use random repetitions, which are Monte Carlo. For your file, the interval at each required size is:

{{intervals clinic}} {{intervals costs}} {{intervals heart}}

Exact results do not depend on a seed. Monte Carlo results do, so compare several seeds before trusting small differences.

What does RMSE add to bias and SD?

RMSE is the typical size of the error of one estimate, counting both a consistent offset (bias) and random scatter (SD): RMSE² = bias² + SD², with SD calculated by dividing by the number of repetitions (or starts). It is in the same units as your target, so you can say “a typical estimate is off by about … {{sc units}}”.

My prediction was wrong. Is that a problem?

Claims to avoid
  • Calling a method biased because one sample missed the true mean.
  • Treating a small Monte Carlo bias that changes sign with the seed as evidence of real bias.
  • “Smaller spread means no bias.” Spread and bias are separate questions.
  • Calling a method the best without saying for which population, which n, and by which measure.
  • Combining estimates from different seeds, methods, sizes or conditions into one set.
